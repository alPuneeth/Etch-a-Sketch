# Etch-a-Sketch

A browser-based Etch-a-Sketch drawing grid built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Interactive drawing grid with a default size of 16 × 16.
- Hover over squares to change their colors.
- Generate random RGB colors on hover.
- Resize the grid by entering a custom size between 1 and 100.
- Progressive darkening: squares become darker with repeated hovers until they reach black.

## Built With

- HTML5
- CSS3
- JavaScript

## Live Demo

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alPuneeth/Etch-a-Sketch.git
   ```
2. Open the project directory.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.
